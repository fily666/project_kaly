# Kaly — Guías de herramientas en Kali Linux

Apuntes prácticos de herramientas de reconocimiento y OSINT en Kali Linux.

> ⚠️ Todo el contenido es con fines educativos. Usar únicamente sobre objetivos propios, autorizados o dentro de un laboratorio.

## Estructura de cada guía

Todas las guías siguen el mismo formato:

1. **Título** — `HERRAMIENTA — descripción corta`
2. **Encabezado** — categoría, objetivo, repositorio (si aplica) y aviso de uso
3. **Pasos numerados** — `## 1. ...`, con el comando en un bloque de código y un **Ejemplo**
4. **Resumen** — tabla final con todos los comandos

Para agregar una herramienta nueva, copiar cualquier guía existente como plantilla y añadirla al índice.
